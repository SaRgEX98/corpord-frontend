# Справочники России: загрузка по запросу

Frontend требует backend с миграцией `20261103000100` и cursor API `/catalog/:kind`.
Развёртывать backend перед frontend; старые list endpoints ограничены 100 записями.
Все изменения ниже относятся к этому варианту, а не к историческим PR.

- Каталоги/админтаблицы: 30 строк с сервера, без выгрузки всего списка и локального
  поиска по стране. `Показать ещё` использует непрозрачный cursor; смена запроса
  сбрасывает cursor. В памяти/DOM остаются последние 200 строк.
- Поля городов/остановок: debounce 250ms, AbortController, generation guard,
  ограниченный LRU на 32 запроса и TTL 30s. Кэш привязан к экземпляру компонента;
  в ключ входят текст, исходная точка и выбранный регион. Приватные API не кэшируются.
- Регион в подсказках служит уточнением списка городов, не становится from_id/to_id.
  Одинаковые имена остановок различаются городом/регионом/адресом.
- Административные связанные селекторы ничего не загружают до фокуса. При открытии
  редактора подгружаются только уже выбранные значения по ID/точному имени. Новые
  варианты загружаются страницами и ищутся сервером. Выбор хранит настоящий ID.
- Overview получает одну сводку приблизительных PostgreSQL planner estimates
  (`≈`), а не полные массивы всех девяти ресурсов.
- Расписание/календарь/quote: серверные результаты, без quote запроса на каждую
  карточку. Предыдущий поиск/календарь отменяется при смене параметров. Полные
  остановки рейса загружаются только в детальной карточке через lazy async data.
- MapLibre по-прежнему импортируется/запрашивает ресурсы после кнопки карты;
  сам компонент карты и календарь разделены на ленивые chunks.
- Синтетический рейс и календарь с ним явно помечаются. Открытые геоданные не
  подтверждают расписание, тариф или остаток мест; доступность остаётся unknown.
- В общем footer показана атрибуция OpenStreetMap с прямой ссылкой на источник
  и обозначением ODbL.

Проверки: unit/contract tests API, TTL/LRU, cursor/signal/region encoding;
Playwright `catalog-lazy.spec.ts` проверяет размер страницы, отмену устаревшей
выдачи и переход регион → город. `workspace.spec.ts` проходит девять CRUD с
новыми remote combobox; `routes-integration.spec.ts` использует настоящий API/PG
и сверяет календарь/поиск/quote в другом браузерном часовом поясе.

а не гарантия полноты официального реестра или реального расписания страны.
