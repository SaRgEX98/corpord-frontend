# Проверка качества справочника

Администратор открывает `/admin/catalog-quality`. Очередь содержит остановки с
неподтверждённым городом, страница30/окно200; строка показывает адрес, координаты и
использование в расписании. Отдельная сводка не запрашивается на каждую строку.

«Проверить» открывает форму и последние20 событий выбранной остановки. Список
городов загружается при фокусе комбобокса; выбор явный, без nearest-city эвристик.
После выбора требуется основание5..500 символов. Сохранение отправляет актуальную
версию и не повторяется автоматически при сетевой ошибке. При неясном исходе
обновление очереди/истории позволяет проверить результат.

Используемые остановки защищены сервером. stale_version требует обновления очереди;
stop_in_use/timezone_conflict объясняются серверным сообщением. После успеха строка
уходит из очереди, форма показывает город и audit; персональные данные редактора
не загружаются, отображается только его ID. Все очередные запросы имеют отмену и
защиту от устаревших ответов. Страница защищена admin middleware плюс backend ACL.

Тесты: `tests/catalog-quality.test.mjs` — encoding/cancellation/bounded API/no retry;
`tests/e2e/catalog-quality.spec.ts` — реальный isolated API, login, lazy city picker,
mapping/audit/stale409, mobile/dark overflow. Не запускать E2E против основной dev БД.
