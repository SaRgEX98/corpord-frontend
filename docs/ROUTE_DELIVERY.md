## Границы первого этапа

Реализуется информационный поиск прямого рейса или его участка для одного
пассажира. Новые цены — целые копейки RUB; календарь, выдача и quote используют
одну серверную политику суммы тарифов соседних остановок. `base_price` остаётся
отдельной legacy-величиной и не добавляется повторно. Тариф может быть `null`,
если данные не подтверждены. Новая цена не означает бронь или гарантию места.

День поиска определяется подтверждённым IANA timezone отправления; прибытие —
своим поясом. Остановки сопоставляет администратор, адреса не разбираются для
автоматического назначения городов. Для старых остановок сопоставление — явное
условие включения нового поиска; прежние публичные endpoint сохранены.

OpenStreetMap/MapLibre и собственный Photon выбраны вместо обязательного платного
API. Публичные Nominatim, тайлы OSM и demo Photon не являются зависимостью.
Шаблоны находятся в Git backend `deploy/geo`, действующий `corpord-infra` не менялся.
Настройки: backend `PHOTON_BASE_URL`/`PHOTON_TIMEOUT`; frontend
`NUXT_PUBLIC_MAP_STYLE_URL`/`NUXT_PUBLIC_MAP_DARK_STYLE_URL`. По умолчанию внешние
сервисы не включены; поиск собственных остановок от них не зависит.

## Что остаётся следующим этапом

- Расширить проверенный городской пилот Екатеринбурга на согласованные регионы,
  проверить нагрузку и сопровождение обновлений. Реальные Photon/PMTiles,
  кириллица, sprites, обе темы и ресурсы городского импорта уже проверены;
  покрытие РФ и production SLA из этих измерений не следуют.
- Подтвердить города/timezone существующих остановок на целевом окружении после
  резервного копирования и применения миграции; согласовать смысл старых дат.
- Выбрать достоверный источник мест (перевозчик или контур резервов/продаж).
  До этого статус мест — unknown; вместимость не используется как остаток.
- Утвердить политику сборов/тарифов и спроса. Надбавки, реальные резервы,
  платежи, сезонные правила и ML не включены в информационный этап.

Все изменения проходят PR в `dev`; пользовательские ветки и действующие данные
не перезаписываются. Merge и обновление действующих контейнеров требуют отдельного
шага после ревью. Runtime-геоданные и реальные `.env` в Git не включаются.

## Продолжение: реальный региональный пилот

2026-11-01. Подготовлены собственный Photon с 49 872 документами и настоящая
PMTiles-карта Екатеринбурга (360 тайлов, 6.46 MB), включая свои стили обеих тем,
кириллические шрифты и sprites. Полный воспроизводимый протокол — backend
`deploy/geo/pilot/README.md`, источники/хеши/лицензии закреплены в скриптах.
Публичные геосервисы не используются. Данные остаются вне Git.

На 40 заранее определённых запросах × 3 повтора: 120 успешных HTTP, без
структурных ошибок; все 19 полных имён/адресов найдены. Префиксы и опечатки имеют
известные пропуски. Baseline city известен только у 22.8% объектов. Отдельная копия
индекса уточняет отсутствующий city для точек внутри проверенного контура города
с отступом 100 м; доля с city выросла до 50.7%. Приблизительные центры ways не
обогащаются, неизвестные города сохраняются, ожидаемые результаты поиска сохранены.

Реальная карта выявила missing worker MapLibre 6 в production bundle: исправлено
явным Vite `?url`/`setWorkerUrl`, ленивое подключение сохранено. Выбор города через
настоящий Photon выявил SQL `integer = text` в списке остановок; backend исправлен
и защищён регрессионным тестом с PostgreSQL.

Актуальный полный прогон: Go race/integration + vet PASS; 5 geometry guards PASS;
frontend 45/45 unit/contract PASS, typecheck и production build PASS. Chromium
на production frontend, согласованном backend и отдельных БД: 6 PASS / 1 skip.
Проверены реальная подсказка → явный город → тестовая остановка, настоящие
PMTiles/glyphs, light/dark/mobile без публичных запросов, цены/календарь и девять
CRUD. Пропущен только прежний тест искусственного стиля карты. Отдельный тест
подложки подменяет маршрутные API, тест настоящего Photon подмен API не использует.
Снимки `test-results/real-map-{light,dark,mobile}.png` осмотрены локально.

Развёртывание действующего приложения и настройки geo по умолчанию не менялись.
Пилот не подтверждает остановки посадки перевозчика, остатки, спросовые надбавки
или готовность других регионов. Эти условия остаются отдельными этапами плана.
